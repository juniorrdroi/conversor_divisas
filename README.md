# 📚 Conversor de Divisas (Cotización en vivo)

Este es un proyecto de consola desarrollado en Python que consume la API pública de [DolarApi](https://dolarapi.com/) para obtener las cotizaciones actualizadas del Dólar Oficial y Dólar Blue en Argentina, permitiendo calcular el equivalente de un monto en Pesos Argentinos (ARS) al precio de venta.

## 🚀 Requisitos previos

- Python 3.9 o superior instalado en el sistema.
